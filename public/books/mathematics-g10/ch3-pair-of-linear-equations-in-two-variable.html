Words this chapter explains

  • Linear equationAn equation in which variables appear only to the first power.
  • Pair of linear equationsTwo equations that contain two variables.
  • SolutionValues of the variables that make both equations true.
  • Inconsistent pairA pair of equations with no common solution.
  • Consistent pairA pair of equations that has a solution.
  • Dependent pairA pair whose equations are equivalent and have many common solutions.
  • Unique solutionThe one solution obtained when two lines intersect.
  • Infinitely many solutionsEvery point on a coincident line is a solution.
  • Parallel linesLines that do not meet, so the pair has no solution.
  • Coincident linesTwo lines lying on the same line.
  • Substitution methodA method that replaces one variable with an expression for it.
  • Elimination methodA method that removes one variable before solving.
  • CoefficientsThe numbers multiplying the variables in an equation.
  • Graphical methodA method that solves the pair by drawing the two lines.
  • Non-zero constantsNumbers used for multiplying equations that are not zero.
