Words this chapter explains

  • measures of central tendencyThese numbers represent the centre of a set of data.
  • meanThe sum of all observation values divided by the number of observations.
  • medianThe middle observation after the values are arranged in order.
  • modeThe observation value that occurs most often.
  • frequencyThe number of times an observation value occurs.
  • class intervalA group into which observation values are placed.
  • class markThe average of the upper and lower limits of a class.
  • class sizeThe gap between the limits of a class interval.
  • cumulative frequencyThe running total after adding frequencies up to a class.
  • ogiveA curve drawn using cumulative frequencies.
  • modal classThe class interval with the greatest frequency.
  • assumed mean methodA method that uses a chosen class mark as an assumed mean.
  • step-deviation methodA method that divides each deviation by the class size.
  • median classThe class interval containing the middle position of grouped data.
  • deviationThe difference between a class mark and the assumed mean.
