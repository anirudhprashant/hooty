Words this chapter explains

  • distributive propertyThis property multiplies a sum by multiplying each part and adding the products.
  • commutative propertyThis property allows the order of two multiplied numbers to be changed.
  • algebraic expressionAn algebraic expression contains numbers, letters and operations.
  • identityAn identity is an equality that is true for all allowed values of its letters.
  • letter-numbersLetter-numbers are the letters used as numbers in an algebraic expression.
  • like termsLike terms have exactly the same letter-numbers and can be added together.
  • exponent notationExponent notation writes repeated multiplication in a shorter form using powers.
  • square of the sumThis is the squared value of two numbers added together.
  • square of the differenceThis is the squared value of the first number minus the second number.
  • difference of two squaresThis is the square of the first number minus the square of the second.
  • khaṇḍa-guṇanamThis ancient term refers to multiplying by parts and then adding the products.
  • ista-gunanaThis name refers to Brahmagupta's method of fast multiplication using distributivity.
  • BrahmasphuṭasiddhāntaThis is the work in which Brahmagupta described the distributive property and fast multiplication.
  • sidelengthSidelength is the length of one side of a shape.
