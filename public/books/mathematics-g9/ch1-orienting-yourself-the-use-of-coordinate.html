Words this chapter explains

  • coordinate systemA structured framework that uses numbers to describe exact locations.
  • grid-based thinkingThinking about locations by using an organised grid.
  • coordinate geometryThe use of coordinates to describe points and geometric shapes.
  • Celestial CoordinatesCoordinates that measure positions from the ecliptic.
  • eclipticThe path followed by the sun and used as a reference for coordinates.
  • longitude meridianA north–south reference line used for measuring other locations.
  • astrolabeA handheld device that helped sailors find coordinates by looking at stars.
  • originThe point where the x-axis and y-axis meet.
  • coordinate axesThe horizontal x-axis and vertical y-axis used to locate points.
  • Cartesian planeThe plane containing the coordinate axes.
  • quadrantOne of the four parts into which the coordinate axes divide the plane.
  • x-coordinateThe perpendicular distance of a point from the y-axis, measured along the x-axis.
  • y-coordinateThe perpendicular distance of a point from the x-axis, measured along the y-axis.
  • Baudhāyana–Pythagoras TheoremA theorem used to find a distance from perpendicular coordinate differences.
  • distance formulaA rule using squared horizontal and vertical changes to find distance.
