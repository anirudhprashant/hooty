Words this chapter explains

  • algorithmA systematic set of steps for solving a problem.
  • carryA value passed to the next column on the left.
  • basic stepA small action that an algorithm assumes we can already perform.
  • divisorA factor of a number, found by checking possible numbers.
  • greatest common divisorThe largest divisor shared by two numbers.
  • listAn ordered collection of values kept for later use.
  • data structureA way to organise information so that an algorithm is more efficient.
  • common divisorA divisor that appears for both numbers.
  • most-recent-common-divisorThe largest common divisor found so far during the final scan.
  • ascending orderArranged from smallest to largest.
  • Euclid’s subtraction algorithmA gcd method that replaces gcd(m, n) with gcd(n, m-n).
  • Āryabhaṭa’s division algorithmA gcd method that uses m mod n instead of m minus n.
  • long divisionA concise way to carry out the remainder-based gcd method.
  • inputThe numbers or values given to an algorithm.
