Words this chapter explains

  • DataFacts, numbers, measures or observations that give information about things.
  • Data collectionThe process of gathering information for a question or inquiry.
  • Tally marksShort strokes used to count choices or observations.
  • FrequencyThe number of times a value or observation occurs.
  • Frequency distribution tableA table that shows each value and how often it occurred.
  • Ascending orderThe order in which values are arranged from smallest to largest.
  • PictographA display that represents data using pictures, objects or symbols.
  • ScaleThe value represented by each unit, picture or symbol.
  • KeyThe part of a graph that explains what each symbol means.
  • CategoryA group of items that is compared within the data.
  • Bar graphA graph that uses equal-width bars to show frequencies or quantities.
  • Column graphA bar graph in which the bars are vertical.
  • InfographicA visual presentation that uses attractive pictures and design to communicate information.
  • InferenceAn understanding or conclusion gained by studying the data.
